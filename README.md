# Tasker
Tasker helps you keep track of your tasks for the day. It is a pretty basic to-do list web application.<br>
You can add your tasks for the day and check them off once you complete them. There is a cross off button to delete tasks as well. Your progress is tracked by the progress bar. It dynamically adjusts based on the number of tasks you add, delete, and check off.<br>
I hope you like it!
